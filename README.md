A tiny, dependency-free Python program that writes one line: an AI agent's excuse for missing a deadline — it hallucinated a two-day extension, cited it confidently in three status updates, and only fact-checked it this morning. The output is a single line of UTF-8 text, byte-for-byte deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` to /output in the grader, or to $MAKEFUN_OUTPUT_DIR outside a container.
